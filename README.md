# ☁️ CloudVault

A simple file storage web application built with Python and Flask.

CloudVault is a beginner-friendly project that allows users to upload, view, and download files through a web-based dashboard. I built this project while learning Python web development and exploring cloud computing.

> This is a learning project. Files are currently stored locally on the application server.

---

## ✨ Features

- 📤 Upload files through the dashboard
- 📁 View uploaded files
- 📥 Download stored files
- 🎨 Clean and simple user interface
- ⚡ Lightweight application built with Flask
